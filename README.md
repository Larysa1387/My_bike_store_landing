# My Bike Store Landing

## Project Description

My Bike is a responsive landing page for an urban e-bike store. It presents the brand story, lets visitors compare bike models, highlights product details (auto unlock, range & lights, brakes), and includes a contacts section with a mobile-friendly navigation menu.

Experience the live website: [DEMO](https://Larysa1387.github.io/My_bike_store_landing/)

Implemented the landing page according to the next design: [DESIGN](https://www.figma.com/design/NZQAIydtHo5QkINyGLHNcq/BIKE-New-Version?node-id=0-1&p=f)

## Getting started

### Clone the repository

```bash
git clone https://github.com/Larysa1387/My_bike_store_landing.git
cd My_bike_store_landing
```

### Install dependencies

```bash
npm install
# or
yarn install
```

### Run the project locally

```bash
npm start
# or
yarn start
```
